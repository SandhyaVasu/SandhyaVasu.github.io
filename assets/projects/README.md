Project figures go here.

Name the file after the project's Markdown file and it is picked up
automatically — no front-matter change needed:

    _projects/gensemble.md          ->  assets/projects/gensemble.png

Any of .png .jpg .jpeg .webp .gif .svg works. To use a different filename,
name it explicitly in the project's front matter instead:

    image: some-other-name.png

Until a project has a figure, its slide shows a placeholder.
